## Project Title
Smart Pet Feeder

## Project Overview

Smart Pet Feeder is an automatic pet feeding system developed using ESP32. The system can dispense pet food automatically according to a scheduled feeding time. Users can also feed their pets manually using a push button.

The system can monitor the food level and alert the user when the food is low or empty. It can also detect the pet, count the number of times food is dispensed, and count how many times the pet comes to eat each day. The system displays information on an OLED screen and uses LEDs to show the current system status.
