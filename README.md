# Smart-Pet-Feeder
 Smart Pet Feeder

Project Overview

Smart Pet Feeder is an automatic pet feeding system developed using ESP32.
The system can dispense pet food automatically according to a scheduled feeding time. Users can also feed their pets manually using a push button.

The system monitors the food level, detects the pet, and displays system information on an OLED screen.

Features

- Automatic feeding
- Manual feeding
- Pet detection
- Food-level monitoring
- OLED display
- LED status indicators
- Daily feeding count

Hardware

- ESP32
- Servo Motor
- OLED 
- Push Button
- Potentiometer
- Ultrasonic
- LEDs
