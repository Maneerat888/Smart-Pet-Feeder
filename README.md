# Smart-Pet-Feeder
 Smart Pet Feeder

Project Overview

Smart Pet Feeder is an automatic pet feeding system developed using ESP32. The system can dispense pet food automatically according to a scheduled feeding time. Users can also feed their pets manually using a push button.

The system can monitor the food level and alert the user when the food is low or empty. It can also detect the pet, count the number of times food is dispensed, and count how many times the pet comes to eat each day. The user can also adjust the food amount to 3 levels. An OLED display shows important system information, while LEDs indicate the current system status.

Features

- Automatic Feeding — Dispenses pet food automatically according to the scheduled time.
- Manual Feeding — Allows users to dispense food manually using a push button.
- 3-Level Food Amount Control — Allows users to adjust the amount of food to 3 levels.
- Food Level Monitoring — Monitors the food level in the container.
- Low Food Alert — Alerts the user when the food level is low.
- Empty Food Alert — Alerts the user when the food is empty.
- Pet Detection — Detects when the pet comes near the feeder.
- Daily Pet Visit Counter — Counts how many times the pet comes to eat each day.
- Feeding Counter — Counts the number of times food has been dispensed.
- OLED Display — Displays food level, feeding information, pet visits, and system status.
- LED Status Indicators — Shows the current system status using LEDs.

Hardware

- ESP32
- Servo Motor
- OLED 
- Push Button
- Potentiometer
- Ultrasonic
- LEDs
